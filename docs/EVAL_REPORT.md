## 模式对比（重排开启 vs 关闭）

| 模式 | 命中率 | 拒答率 | 说明 |
| --- | --- | --- | --- |
| `none`（一阶段检索） | 92%（11/12） | 100%（3/3） | 混合检索直接取 Top-4 |
| `offline`（离线精排，默认） | 92%（11/12） | 100%（3/3） | Rerank 精排后取 Top-4 |

> 说明：当前演示知识库仅 33 个片段、检索信号充足，两类模式命中率一致（仅「在家连不上公司的远程办公网络」因查询词与 VPN 文档用词无重叠而未命中，属离线向量的语义局限，非重排问题）。Rerank 的价值在**更大知识库 / 更难问题上更明显**——评测脚本已就绪（`--rerank none/offline/llm` 一键对比），接入真实语义向量或 bge-reranker 后可量化验证。

## 复现方式

```bash
python scripts/evaluate.py --rerank offline   # 默认模式（免密钥精排）
python scripts/evaluate.py --rerank none      # 关闭重排对比
python scripts/evaluate.py --rerank llm       # 大模型重排（需 LLM_API_KEY）
```
