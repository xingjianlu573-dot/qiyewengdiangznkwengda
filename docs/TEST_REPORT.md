## 四、API 冒烟验证覆盖（scripts/api_smoke_test.py）

- 健康检查：状态 ok、4 文档 / 33 片段、三种格式统计正确；
- 文档列表：中文文件名编码正确；
- 四类典型问题：全部命中正确文档，引用携带章节与匹配度元数据；
- 库外问题：grounded=False + 「没有找到」文案；
- 上传链路：临时 .md 上传入库 → 可被检索回答 → 可删除 → 索引恢复原状；
- 安全拦截：非白名单格式返回 415。

## 五、已知限制

| 限制 | 说明 |
| --- | --- |
| 扫描件/纯图片 PDF | 暂不支持 OCR，解析时报错并给出明确提示 |
| 离线向量精度 | 哈希向量仅支持关键词级召回；接入 API Embedding 后获得语义级精度（架构已支持，配置即切换） |
| 会话记忆 | 当前为单轮问答，多轮上下文列入路线图 |
| 权限控制 | 文档级 ACL 列入路线图，当前适合部门内部共享场景 |
