# Windows 电脑故障处理手册

> 适用范围：企业桌面运维。按症状查表处理，处理后统一在工单系统登记。

## 一、蓝屏错误速查

| 蓝屏代码 | 常见原因 | 处理步骤 |
| --- | --- | --- |
| 0x0000007B | 启动磁盘 / 硬盘控制器驱动问题（INACCESSIBLE_BOOT_DEVICE） | 进 BIOS 检查硬盘模式（AHCI/RAID），修复系统引导，检查硬盘是否损坏 |
| 0x0000000A | 驱动或硬件内存访问冲突 | 更新驱动，检测内存（Windows 内存诊断），移除最近安装的硬件 |
| 0x0000001E | 系统服务或驱动异常 | 查看蓝屏文件 minidump，卸载最近更新，回滚驱动 |
| 0x000000D1 | 驱动程序访问异常内存（常见于网卡/显卡驱动） | 更新或回滚驱动，禁止内存转储为 0 |
| 0x00000050 | 内存错误或驱动问题 | 运行内存诊断，更换内存插槽测试 |

通用处理顺序：
1. 记录蓝屏代码与 STOP 信息（拍照留存）；
2. 重启电脑，若反复蓝屏则进入安全模式（开机时连按 F8 或使用高级启动）；
3. 安全模式下卸载最近安装的软件 / 驱动 / 更新；
4. 运行 `sfc /scannow` 与 `DISM /Online /Cleanup-Image /RestoreHealth` 修复系统文件；
5. 仍无法解决：备份数据后重装系统，并转硬件检测。

## 二、电脑运行缓慢

1. 任务管理器 → 启动，禁用非必要开机自启项；
2. 检查磁盘剩余空间（C 盘建议保留 20% 以上），清理临时文件（运行 `%temp%`，磁盘清理工具）；
3. 任务管理器查看 CPU / 内存占用：占用长期 90%+ 时定位进程，杀毒全盘扫描排除挖矿/木马；
4. 机械硬盘建议做碎片整理（defrag），SSD 检查健康状态（CrystalDiskInfo）；
5. 更新系统补丁与显卡驱动，重启观察。

## 三、无法开机

1. 先查电源：按电源键是否有反应、电源灯是否亮；
2. 拔掉所有外设（U 盘、移动硬盘、打印机）后重启，排除外设引导干扰；
3. 开机画面出现前连按 F8 / Shift+F8 进入高级启动，选择「安全模式」；
4. 安全模式能进：说明是驱动或软件问题，回滚最近更新、卸载问题软件；
5. 安全模式也进不去：使用 Windows 安装介质进入「修复计算机」→ 启动修复；
6. 启动修复无效：检查硬盘与内存（PE 工具检测），必要时重装系统。

## 四、打印机无法打印

1. 确认打印机电源与指示灯状态，纸盒有纸、无卡纸；
2. 检查打印任务队列：删除卡住的任务，重启「Print Spooler」服务（services.msc → Print Spooler → 重新启动）；
3. 重新安装或更新打印机驱动；共享打印机检查主机是否开机；
4. 检查端口：打印机属性 → 端口，确认端口指向正确 IP（网络打印机）；
5. 测试页：Windows 自带「打印测试页」验证驱动与端口。

## 五、系统更新失败

1. 停止更新相关服务：Windows Update、BITS、Cryptographic；
2. 删除更新缓存：清空 C:\Windows\SoftwareDistribution\Download 目录；
3. 重启上述服务，重新检查更新；
4. 仍失败：运行 Windows Update 疑难解答工具，或手动下载对应补丁安装；
5. 注意：更新失败不会导致系统无法使用，可先安排业务空闲时间处理。

## 六、磁盘与文件问题

- C 盘满了：迁移大文件（视频/安装包）到 D 盘，清理系统缓存与回收站；
- 文件被占用无法删除：任务管理器结束对应进程，或重启后删除；
- 磁盘坏道 / 异常：管理员运行 `chkdsk C: /f`（需重启），并提前备份重要数据；
- 误删文件：立即停止写入该磁盘，尝试回收站或数据恢复工具，重要数据走备份恢复。

## 七、账号与安全

- 账号被锁定：等待策略时间自动解锁，或由管理员在 AD 域控中解锁并重置密码；
- 忘记密码：通过公司自助重置门户（SSPR）重置，或联系 IT 部门验证身份后重置；
- 杀毒软件提示风险：先隔离，核对文件来源，禁止关闭杀毒软件运行未知程序。
